***Design Task Management system***

Functional Requirements:

- users can create a task(name, des, time, priority, status)
- update a task
- delete a task
- add collaborators
- assign tasks to other users
- set reminders
- view task history 

- handle concurrent access to tasks and ensure data consistency
- system should be extensible to accommodate extensions


Classes:

Task Management:

- Task_list: {id: Task}
- User_list: {id: User}
- map: {User: [Task]}

* create_task(user_id, task_id)
* update_task(user_id, task_id)
* delete_task(user_id, task_id)

* assign_task(user_id, task_id, another_user)
* set_reminder(user_id, task_id, day)
* filter(user_id, Strategy)

* view_history(user_id)



enum class TaskStatus:
- pending
- in progress
- complete
- deleted

User:

- user_id
- name
- email

- history: {task_name: Task_obj}


Task:


- task_id
- task_name
- des
- time
- status
- collaborators
- priority: 1 to n
